# Local font assets

Latin normal variable WOFF2 files from the Fontsource packages below, version 5.3.0. Each family's original SIL Open Font License is included next to its font file.

| File | Family | Weight range | Source package |
| --- | --- | --- | --- |
| `inter.woff2` | Inter | 100–900 | `@fontsource-variable/inter` |
| `inter-tight.woff2` | Inter Tight | 100–900 | `@fontsource-variable/inter-tight` |
| `jetbrains-mono.woff2` | JetBrains Mono | 100–800 | `@fontsource-variable/jetbrains-mono` |

These assets let the website retain its original typography without an external font request. Configure `font-style: normal` and `font-display: swap` when declaring each family.

Sources: https://registry.npmjs.org/@fontsource-variable/inter, https://registry.npmjs.org/@fontsource-variable/inter-tight, https://registry.npmjs.org/@fontsource-variable/jetbrains-mono.
