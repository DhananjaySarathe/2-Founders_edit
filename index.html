Work we've shipped

Framecast

When we started making videos, streaming software kept getting in the way. So we built our own studio for the Mac, and then open-sourced it.

Framecast streams and records a landscape and a vertical show at the same time. An AI director listens to what you say and switches layouts and graphics as you reach each topic. Don't like a switch? One shortcut takes it back.

What it is
macOS app, free and open source
Built for
Ourselves first, now anyone who streams

See Framecast Source on GitHub

AI Editor

A creator wanted every edit to look like theirs, every time, without briefing an editor from scratch.

We went through their videos and reels, turned how they cut, caption and pace into a set of custom skills, and built a Claude-based editor around them. Raw footage goes in; an edit in their style comes out, consistently.

What it is
Claude-based AI video editor with custom skills
Built for
A client. The code stays private.

ExpenseWaale

A bill-splitting app built to go head to head with the one everyone already uses, for flatmates, trips and office lunches.

Keep a separate space for each group, split any expense equally, by shares or by percentage, and settle up in the fewest payments possible. Reports export as a PDF or a share link.

What it is
Web app for shared expenses
Built for
Groups who are done with spreadsheets

Open ExpenseWaale

StockTax Pro

A client needed Indian traders to see exactly what tax they owe, and how much of it they can still legally offset before March 31.

Import trades straight from Angel One, Kite or Upstox. It separates short-term and long-term capital gains and F&O, then points out which losing positions to book so the loss sets off your gains.

What it is
Capital-gains tax and loss-harvesting tool
Built for
A client, for traders in India

Open StockTax Pro

Liquid Signal

A Chrome extension that reads a YouTube video's comments so you don't have to, and tells you what the audience actually wants next.

Ask your own question or take a suggested one, and Liquid Signal sorts a sample of public comments into 2 to 6 answers, writes a plain-language summary, and exports the findings as CSV or JSON.

What it is
Chrome extension, on the Web Store
Built for
Creators and marketers reading their audience

Get Liquid Signal

Assistant

A client in the US wanted one chat window to run their calendar, inbox, tasks and expenses. We built it in n8n, back when AI agents couldn't do this out of the box.

You type a request into a Streamlit chat. An n8n AI agent works out what you mean, calls the right Google tool, and replies in the same chat: create an event, read Gmail, add a task, update a note, log an expense to Sheets.

What it is
n8n AI agent with a Streamlit chat
Built for
A client in the US
